# AMT: Auroral Multi-Task Deep Learning Model

This repository contains the source code, inference scripts, and evaluation scripts for the manuscript:

"Multi-Task Deep Learning Net of Solar Wind Driven Global Auroral Particle Precipitation"

## Contents
- `method/`: model achitecture
- `evalustion/ `: inference scripts, and evaluation scripts

## Data

The raw data are not redistributed in this repository. They can be obtained from the official OMNI, DMSP/SSJ, and IMAGE auroral boundary data archives.
